정년계열 전임교원 업적평가 시행안내

□ 평가대상 : 정년계열 전임교원

□ 평가기간 : 2026.01.01. \~ 2026.06.30.

□ 세부안내

○ 전임교원

- 업적자료 담당부서로 제출(2026.01.01. \~ 2026.06.30.에 취득한 실적)

- 실적확인 후 이상 시 해당 부서로 정정요청

◎ 업적평가 점수 열람경로 : 통합정보시스템 → 일반행정 → 인사/총무 →
개인인사관리 → 개인업적조회(교수용)

○ 행정부서(관련학과 및 부서)

- 통합정보시스템에 자료 입력 및 승인 [승인상태여야 해당교원이 확인 가능]

- 업적평가점수 확인기간에 정정사항 발생 시 실적 수정

- 확인기간 종료 후 완료된 실적을 부서[학과(부)장]의 업무결재 후 자료제출

◎ 전산시스템 작업경로 : 통합정보시스템 → 일반행정 → 인사/총무 →
교원업적평가 → 업적자료입력(담당부서) → 평가자료 입력(연계 또는 입력)
→ 업적승인 → 업적확인 및 정정 기간 → 결재의뢰(부서장/학과(부)장 업무결재)
\* (내부)결재완료 후 정정사항 발생 시 교무처로 개별 연락 요망

○ 평가항목

- 「교원업적평가항목」 참조(붙임 2)

□ 세부일정(안)

| 일 정 | 내 용 | 담당부서 |
| --- | --- | --- |
| 2026. 6. 25. | - 교원업적평가 시행 안내 | - 교무팀 |
| 6. 29. \~ 7. 3. | - 교원 본인실적 평가부서에 신고 | - 교원 |
| 7. 6. \~ 7. 8. | - 실적입력 및 업적승인 완료 | - 평가항목 담당부서 |
| 7. 9. \~ 7. 13. | - 평가점수 확인 및 정정요청<br>- (누락)추가실적 제출 | - 교원 |
| 7. 14. \~ 7. 15. | - 자료제출(부서장 결재의뢰)<br>\*업적이 없는 경우에도 교무팀 제출 | - 평가항목 담당부서 |
| 7. 16. | - 업적평가 자료 확정 | - 교무팀 |

업적자료 입력 및 제출 방법

### 시스템 연계

(1) 통합정보시스템 – 일반행정 – 교원업적평가 – 업적등록 – 업적자료입력

(담당부서)로 접속

(2) 평가년도, 평가분기, 평가계열(정년계열 정기) 설정 후 조회

→ “2026년 상반기”로 설정하여 조회

[이미지: BIN0001.tif]

(3) 연계하고자 하는 평가항목을 선택 후 우측의 업적자료생성 버튼을 클릭

→ 확인 메시지 선택

[이미지: BIN0002.tif]

(4) 연계된 자료를 선택(체크박스)하여 업적승인

→ “업적승인”을 해두면 교원이 실적 확인 가능

[이미지: BIN0003.tif]

(5) 26년 7월 14일 이후(평가점수 확인기간이 경과한 후), 업적 승인된 평가항목을 결재의뢰(업무결재)하여 내부결재 완료하면 주관부서(교무팀)에 자료제출 완료

→ 결재의뢰 후 취소 가능

![image](image_001.png)

※ 유의사항

(1) 연계자료는 추가/삭제가 불가능하며, 연계자료에 오류가 있을 시 원자료의 데이터 확인이 필요함

(2) 원자료에 오류가 없을 시 연계자료의 추가/삭제는 정보시스템팀 담당자

(김현규 선생님/내선 0274)에게 요청

(3) 경과한 이전 실적에 대한 소급처리는 “업적소급처리” 항목의 “소급처리”

버튼을 눌러 처리 가능(소급처리 대상일자를 설정, 데이터 등록 가능)

① 평가항목별 업적소급처리 버튼 선택

[이미지: BIN0005.tif]

② 소급실적의 평가기간을 설정하여 조회한 후 해당되는 실적을 체크하여 확인

[이미지: BIN0006.tif]

### 수기입력

(1) 통합정보시스템 – 일반행정 – 교원업적평가 – 업적등록 – 업적자료입력

(담당부서)로 접속

(2) 평가년도, 평가분기, 평가계열(정년계열) 설정 후 조회

[이미지: BIN0007.tif]

(3) 해당 평가항목을 선택 후 추가버튼 선택

[이미지: BIN0008.tif]

(4) 「업적평가 상세자료 팝업」에 실적 등록 및 저장

→ “업적승인”상태에서 교원의 실적 확인이 가능

→ 업적정정 또는 추가실적 입력이 필요시 업적승인취소 후 작업

① 개별 업적승인 / 업적승인 취소 가능

- 평가항목별 지정된 업적내용을 등록 후 저장하고 팝업창에서 업적승인 완료

[이미지: BIN0009.tif]

② 교원평가자료 입력창에서 개별 또는 일괄 업적승인 가능

- 팝업에서 저장한 업적내용을 입력창에서 개별 또는 일괄 업적승인

[이미지: BIN000A.tif]

(5) 26년 7월 14일 이후(평가점수 확인기간이 경과한 후), 승인 완료된 평가항목을 결재의뢰 버튼을 눌러 업무결재 진행

→ 결재의뢰하여 결재 완료된 데이터는 수정이 불가함

(결재의뢰 후 수정이 필요한 경우에는 교무팀으로 문의 요망)
